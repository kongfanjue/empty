# 登录页面

一个现代化的登录页面，采用纯 HTML、CSS 和 JavaScript 构建。

## 功能特点

- 🎨 现代化 UI 设计，渐变背景
- 📱 响应式布局，支持移动端
- ✨ 流畅的动画和过渡效果
- 👁️ 密码显示/隐藏切换
- ✅ 实时表单验证
- 🔄 登录按钮加载状态
- 🔗 社交账号登录（微信、GitHub）

## 文件结构

```
/
├── login.html    # 主页面
├── styles.css    # 样式文件
├── script.js     # 交互逻辑
└── README.md     # 说明文档
```

## 使用方法

直接在浏览器中打开 `login.html` 文件即可预览登录页面。

## 表单验证

- 邮箱：必须是有效的邮箱格式
- 密码：最少 6 位字符

## 自定义

可以通过修改 `styles.css` 中的 CSS 变量来自定义主题颜色：

```css
:root {
    --primary-color: #6366f1;
    --primary-hover: #4f46e5;
    /* ... 其他变量 */
}
```
